第一步

能为你做什么

Bloom 会根据你所处的阶段调整自己——经期、备孕、怀孕、宝宝出生后的几个月，或更年期。选一次就好，生活往前走时再换。

在哪里

开始 → 我 → 你的阶段

怎么用

  1. 打开 Bloom，点开始。选择你所在的阶段，再回答几个简短的问题。
  2. 底部的栏：今天是你的这一天，旅程是一周周、一月月，我们是你的家人朋友，我是你的设置。
  3. 栏中间的圆形 +（记录一下）在任何页面都能记录。右上角的按钮打开 Bloom（问问 Bloom）。
  4. 要换到另一个阶段：我 → 你的阶段，然后选择。你记录过的一切都会跟着你。
  5. 我 → 语言更改 Bloom 的语言；通知设置温和的提醒。
  6. 如果你需要 Bloom 安静下来——在失去之后，或出于任何原因——我 → 我需要暂停一下 → 暂停一切。什么都不会删除，准备好了再回来。

周期

能为你做什么

知道自己在周期的哪一天、接下来会怎样。Bloom 从你记录的经期中学会你的节奏，并显示接下来的日子。

在哪里

今天 · 旅程

怎么用

  1. 月经来了，点 + 并选择经期开始。结束时，在今天里点你的经期，选择今天结束了。
  2. 用同样的方式记录感受：心情和症状。
  3. 今天显示周期的第几天、所处阶段——例如易孕期——以及下次月经大概什么时候来。
  4. 旅程里是整个月。点任意一天：查看、补记，或添加预约。
  5. 要修改经期的日子，在今天里点它（你的经期）：第一天、最后一天，或删除这次经期。以前的经期：旅程 → 那一天 → 修改这次经期。
  6. 有检查要去？+ → 预约，并选好日期。之后要修改或删除：旅程 → 那一天 → 点这个预约。

备孕

能为你做什么

你的信号——早晨体温、排卵试纸、分泌物——会移动你的易孕期，Bloom 也会告诉你依据的是哪个信号。

在哪里

今天 · +

怎么用

  1. 每天早上点 + → 基础体温，填入体温。
  2. 用同样的方式记录排卵试纸和分泌物——愿意的话也记录性生活。
  3. 今天按天显示易孕期，它会随你的记录而移动。
  4. 做了验孕，就记下来：+ → 验孕。
  5. 月经来了：+ → 经期开始。修改日子的方法和周期部分一样。

需要知道

易孕期是估算。Bloom 不是避孕方法，也不是医疗器械。

怀孕

能为你做什么

一周一周：宝宝怎样长大、这周会有什么、你的产检——到时候还有胎动计数和宫缩计时。

在哪里

今天 · 旅程

怎么用

  1. 今天显示你的孕周和宝宝的成长；旅程一周一周往下看。
  2. 要数胎动，在今天里点数胎动：会打开胎动计数。（Pro 工具。）
  3. 临产时，+ → 宫缩计时为每次宫缩计时。（Pro 工具。）
  4. 用 + → 预约添加产检，哪一天都可以。要修改或删除：旅程 → 那一天 → 点这个预约。
  5. 宝宝出生后：我 → 宝宝出生了。Bloom 会转到宝宝出生后的几个月，你记录的一切都会跟着你。

需要知道

如果你感觉胎动比平时少，或者变慢、停止，请立刻给助产士或产科病房打电话，任何时间都可以。你不会给任何人添麻烦。

新生儿

能为你做什么

喂奶、睡觉、换尿布，一点就记——凌晨三点也一样。分侧记录吸奶，还有冷藏和冷冻里存着的母乳。

在哪里

今天

怎么用

  1. 开始喂奶时，点喂奶，选择左侧、右侧或奶瓶。
  2. 睡觉开始睡眠计时；宝宝醒来时点醒了。
  3. 尿布：尿湿、便便或都有。
  4. 吸奶分侧为吸奶计时——左侧、右侧或两侧——并记住你吸了多少。
  5. 你的母乳：有多少母乳、放在哪里——冷藏和冷冻。
  6. 夜里：我 → 夜间模式把 Bloom 调暗，方便单手喂奶。

更年期

能为你做什么

症状、潮热和周期随时间的变化，让你看清自己的规律——也能拿给医生看。

在哪里

今天 · +

怎么用

  1. 每次潮热来了，点 + → 潮热。
  2. 用同样的方式记录这一天的其他情况：症状和心情。
  3. 如果还有月经：来的时候 + → 经期开始；结束时 + → 你的经期 → 今天结束了。
  4. 旅程里是整个月。点任意一天：查看、补记，或添加预约。
  5. 我 → 健康摘要生成一份私人摘要，可以拿给医生看。

问问 Bloom

能为你做什么

给 Bloom 写信，或者打电话和她聊。她用平实的话回答，记得你告诉过她的事，也会告诉你什么时候需要看医生或助产士。

在哪里

右上角的圆形按钮（问问 Bloom）

怎么用

  1. 点右上角的圆形按钮。写下问题，点箭头（发送）——或点 Bloom 推荐的问题。
  2. 想直接说话？点给 Bloom 打电话，像和朋友聊天一样说。说完点结束通话。
  3. 朗读——Bloom 会把她的回答读出来。
  4. Bloom 记得你分享的事——你的家人、你的日期——不用每次从头说起。要清除：我 → 隐私与数据 → 忘记 Bloom 学到的一切。
  5. 通话时，Bloom 会学着分辨声音，好叫出你家人的名字。这些声音只留在你的手机上：我 → 隐私与数据 → Bloom 认识的声音。

需要知道

Bloom 的回答是一般信息，不是医疗建议。为了回答，你的问题会经过 Bloom 自己的服务器发送给 Anthropic；通话则从你的手机直接连到 OpenAI。发送了什么，为什么。

家人

能为你做什么

Bloom 属于你，你的家人也可以参与进来：你的圈子、“猜猜看”、写给宝宝的信，还有你的书。

在哪里

我们

怎么用

  1. 我们显示你的圈子：你的伴侣和你添加的人。
  2. 分享近况给你选的人发一条简短的近况——只发你选的内容，只在你发送时发。
  3. 怀孕期间的“猜猜看”：添加第一个猜测（之后是打开猜猜看），再分享猜猜看；每收到一个关于日期和体重的猜测就加进来。
  4. 给宝宝写信，每封都封存到你选的那一天。
  5. 你的书，写到现在：Bloom 一边记录一边帮你写书——每一周、你的记录、你的信、“猜猜看”。它留在你的手机上。
  6. 邀请好友：我们 → 圈子末尾的 +（邀请好友）→ 分享我的邀请码。已经有 Bloom 的好友在同一个地方的有邀请码？下输入你的邀请码，再点兑换。

隐私与数据

能为你做什么

你的日子留在你的手机上。在这里，你可以带走它们、清除它们，并决定 Bloom 保留什么。

在哪里

我 → 隐私与数据

怎么用

  1. 导出我的数据把你记录的一切保存为一个文件。
  2. 删除我的全部数据把这一切从这部手机上抹去。无法撤销。
  3. 忘记 Bloom 学到的一切清除 Bloom 了解到的关于你的事；Bloom 认识的声音让你忘掉她认识的声音。
  4. 备份 Bloom 的记忆：如果你选好，保管我的记忆，Bloom 关于你的记忆笔记的副本——只有这份笔记——会保存在 Bloom 的服务器上，换新手机也还记得你。关掉它，副本就会删除。
  5. 应用锁设置一个 4 位 PIN，每次打开 Bloom 都会要求输入。
  6. 我 → 健康摘要生成一份私人摘要，可以拿给医生或助产士看。

需要知道

什么会离开你的手机、什么时候、为什么：隐私摘要。

Pro

能为你做什么

Bloom 可以免费使用。Pro 只需付一次，永久属于你：完整的逐周孕期内容、胎动计数和宫缩计时——以及以后推出的 Pro 工具。

在哪里

我 → 升级Pro

怎么用

  1. 点我 → 升级Pro——或在 Pro 工具（Pro专属工具）上点解锁Pro。
  2. 会打开你所用商店自己的付款页面——App Store 或 Google Play——商店会显示你所在地的价格。Bloom 从不会看到你的银行卡。
  3. 商店确认后，Pro 就是你的了，Pro 工具随即可用。
  4. 重新安装后，Pro 通常会自动恢复。如果没有，请带着商店的收据写信给我们，我们会帮你处理好。

Bloom 提供的是一般信息，不是医疗建议，也不是避孕方法。 任何关于你健康的问题，请咨询你的医生或助产士。 遇到紧急情况，请拨打当地的急救电话。
