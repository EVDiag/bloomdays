Bloom ทำงานอย่างไร

แต่ละส่วนของ Bloom ทำอะไรให้คุณ หาได้ที่ไหน และใช้อย่างไร — ด้วยคำและหน้าจอของแอปเอง

  1. ก้าวแรก
  2. รอบเดือน
  3. พยายามมีลูก
  4. ตั้งครรภ์
  5. แรกเกิด
  6. วัยหมดประจำเดือน
  7. ถาม Bloom
  8. ครอบครัว
  9. ความเป็นส่วนตัวและข้อมูล
  10. Pro

ก้าวแรก

ช่วยอะไรคุณ

Bloom ปรับตัวตามช่วงที่คุณอยู่ — รอบเดือน การพยายามมีลูก การตั้งครรภ์ ช่วงแรกกับลูกน้อย หรือวัยหมดประจำเดือน เลือกครั้งเดียว แล้วไปต่อเมื่อชีวิตพาไปค่ะ

อยู่ตรงไหน

เริ่มต้น → ฉัน → บทของคุณ

ใช้อย่างไร

  1. เปิด Bloom แล้วแตะ เริ่มต้น เลือกบทที่คุณอยู่ แล้วตอบคำถามสั้นๆ ไม่กี่ข้อ
  2. แถบด้านล่าง: วันนี้ คือวันของคุณ เส้นทาง คือสัปดาห์และเดือน พวกเรา คือคนของคุณ ฉัน คือการตั้งค่า
  3. ปุ่ม + กลมตรงกลางแถบ (บันทึกบางอย่าง) บันทึกได้ทุกอย่าง ไม่ว่าคุณอยู่หน้าไหน ปุ่มมุมขวาบนเปิด Bloom (ถาม Bloom)
  4. ถ้าจะย้ายไปบทอื่น: ฉัน → บทของคุณ แล้วเลือก ทุกอย่างที่คุณบันทึกไว้จะตามไปด้วย
  5. ฉัน → ภาษา เปลี่ยนภาษาของ Bloom ส่วน การแจ้งเตือน ตั้งการเตือนแบบเบาๆ
  6. ถ้าคุณต้องการให้ Bloom เงียบลง — หลังการสูญเสีย หรือด้วยเหตุผลใดก็ตาม — ฉัน → ฉันขอพักก่อน → พักทั้งหมด ไม่มีอะไรถูกลบ และคุณกลับมาได้เมื่อพร้อมค่ะ

รอบเดือน

ช่วยอะไรคุณ

รู้ว่าคุณอยู่ตรงไหนของรอบเดือนและอะไรกำลังจะมา Bloom เรียนรู้จังหวะของคุณจากประจำเดือนที่คุณบันทึก แล้วแสดงวันข้างหน้า

อยู่ตรงไหน

วันนี้ · เส้นทาง

ใช้อย่างไร

  1. เมื่อประจำเดือนมา แตะ + แล้วเลือก ประจำเดือนเริ่มแล้ว
  2. บันทึกความรู้สึกแบบเดียวกัน: อารมณ์ และ อาการ
  3. วันนี้ แสดงวันที่ของรอบ ช่วงของรอบ — เช่น ช่วงเจริญพันธุ์ — และประจำเดือนครั้งถัดไปน่าจะมาเมื่อไร
  4. เส้นทาง มีทั้งเดือน แตะวันใดก็ได้เพื่อดู บันทึก หรือเพิ่มนัดหมาย
  5. มีนัดตรวจ? + → นัดหมาย

พยายามมีลูก

ช่วยอะไรคุณ

สัญญาณของคุณ — อุณหภูมิตอนเช้า ผลตรวจไข่ตก มูก — ขยับช่วงเจริญพันธุ์ของคุณ และ Bloom บอกว่าอิงสัญญาณไหนอยู่

อยู่ตรงไหน

วันนี้ · +

ใช้อย่างไร

  1. ทุกเช้า แตะ + → อุณหภูมิ แล้วใส่อุณหภูมิ
  2. บันทึก ตรวจไข่ตก และ มูก แบบเดียวกัน — และ เซ็กซ์ ถ้าต้องการ
  3. วันนี้ แสดงช่วงเจริญพันธุ์ทีละวัน และขยับตามสิ่งที่คุณบันทึก
  4. เมื่อตรวจการตั้งครรภ์ ให้บันทึกไว้: + → ตรวจครรภ์

ควรรู้

ช่วงเจริญพันธุ์เป็นการประมาณ Bloom ไม่ใช่วิธีคุมกำเนิด และไม่ใช่เครื่องมือแพทย์ค่ะ

ตั้งครรภ์

ช่วยอะไรคุณ

ทีละสัปดาห์: ลูกน้อยเติบโตอย่างไร สัปดาห์นี้มีอะไร นัดหมายของคุณ — และตัวนับลูกดิ้นกับตัวจับเวลามดลูกหดตัวเมื่อถึงเวลา

อยู่ตรงไหน

วันนี้ · เส้นทาง

ใช้อย่างไร

  1. วันนี้ แสดงสัปดาห์ของคุณและการเติบโตของลูกน้อย เส้นทาง ไล่ทีละสัปดาห์
  2. จะนับลูกดิ้น แตะ นับการดิ้น ในหน้า วันนี้: นับลูกดิ้น จะเปิดขึ้น (เครื่องมือ Pro)
  3. ตอนเจ็บครรภ์คลอด + → จับเวลามดลูกหดตัว จับเวลาการหดตัวแต่ละครั้ง (เครื่องมือ Pro)
  4. เพิ่มนัดหมายด้วย + → นัดหมาย
  5. เมื่อลูกคลอด: ฉัน → ลูกน้อยคลอดแล้ว Bloom จะเปลี่ยนไปสู่ช่วงแรกกับลูกน้อย และทุกอย่างที่คุณบันทึกจะตามไปด้วย

ควรรู้

ถ้าคุณรู้สึกว่าลูกดิ้นน้อยกว่าปกติ หรือดิ้นช้าลงหรือหยุดดิ้น ให้โทรหาพยาบาลผดุงครรภ์หรือห้องคลอดทันที ไม่ว่าจะกี่โมงก็ตาม คุณไม่ได้รบกวนใครเลยค่ะ

แรกเกิด

ช่วยอะไรคุณ

การให้นม การนอน และผ้าอ้อมในแตะเดียว — แม้ตอนตีสาม ปั๊มนมแยกข้าง และนมที่คุณมีในตู้เย็นและช่องแช่แข็ง

อยู่ตรงไหน

วันนี้

ใช้อย่างไร

  1. เมื่อเริ่มให้นม แตะ ให้นม แล้วเลือก ซ้าย ขวา หรือ ขวดนม
  2. นอน เริ่มจับเวลาการนอน เมื่อลูกตื่น แตะ ตื่นแล้ว
  3. ผ้าอ้อม: เปียก อึ หรือ ทั้งคู่
  4. ปั๊มนม จับเวลาการปั๊มแยกข้าง — ซ้าย ขวา หรือ ทั้งสองข้าง — และจำว่าคุณปั๊มได้เท่าไร
  5. น้ำนมของคุณ: มีนมเท่าไรและอยู่ที่ไหน — ตู้เย็น และ ช่องแช่แข็ง
  6. ตอนกลางคืน: ฉัน → โหมดกลางคืน หรี่ Bloom ลงสำหรับการให้นมมือเดียว

วัยหมดประจำเดือน

ช่วยอะไรคุณ

อาการ อาการร้อนวูบวาบ และการเปลี่ยนแปลงของรอบเดือนตามเวลา เพื่อให้คุณเห็นรูปแบบของตัวเอง — และนำไปให้แพทย์ดูได้

อยู่ตรงไหน

วันนี้ · +

ใช้อย่างไร

  1. ทุกครั้งที่ร้อนวูบวาบ แตะ + → ร้อนวูบวาบ
  2. บันทึกส่วนอื่นของวันแบบเดียวกัน: อาการ และ อารมณ์
  3. ถ้ายังมีประจำเดือน + → ประจำเดือนเริ่มแล้ว เมื่อเริ่มมา
  4. เส้นทาง มีทั้งเดือน แตะวันใดก็ได้เพื่อดู บันทึก หรือเพิ่มนัดหมาย
  5. ฉัน → สรุปสุขภาพ ทำสรุปส่วนตัวไว้ให้แพทย์ดู

ถาม Bloom

ช่วยอะไรคุณ

เขียนถึง Bloom หรือโทรคุยกับเธอ เธอตอบด้วยคำง่ายๆ จำสิ่งที่คุณเล่าได้ และบอกเมื่อเรื่องไหนควรไปหาแพทย์หรือพยาบาลผดุงครรภ์

อยู่ตรงไหน

ปุ่มกลมมุมขวาบน (ถาม Bloom)

ใช้อย่างไร

  1. แตะปุ่มกลมมุมขวาบน พิมพ์คำถามแล้วแตะลูกศร (ส่ง) — หรือแตะคำถามที่ Bloom แนะนำ
  2. อยากคุยด้วยเสียง? แตะ โทรหา Bloom แล้วพูดเหมือนคุยกับเพื่อน เสร็จแล้วแตะ วางสาย
  3. อ่านออกเสียง — Bloom อ่านคำตอบออกเสียงให้ฟัง
  4. Bloom จำสิ่งที่คุณเล่า — คนของคุณ วันสำคัญของคุณ — คุณจึงไม่ต้องเริ่มใหม่ทุกครั้ง ถ้าจะล้าง: ฉัน → ความเป็นส่วนตัวและข้อมูล → ลืมทุกอย่างที่ Bloom เรียนรู้
  5. ระหว่างโทร Bloom เรียนรู้ที่จะแยกเสียง เพื่อทักทายคนของคุณด้วยชื่อ เสียงเหล่านี้อยู่ในโทรศัพท์ของคุณเท่านั้น: ฉัน → ความเป็นส่วนตัวและข้อมูล → เสียงที่ Bloom จำได้

ควรรู้

คำตอบของ Bloom เป็นข้อมูลทั่วไป ไม่ใช่คำแนะนำทางการแพทย์ เพื่อหาคำตอบ คำถามของคุณจะผ่านเซิร์ฟเวอร์ของ Bloom เองไปยัง Anthropic ส่วนการโทรจะไปจากโทรศัพท์ของคุณถึง OpenAI โดยตรง อะไรถูกส่ง และเพราะอะไร

ครอบครัว

ช่วยอะไรคุณ

Bloom เป็นของคุณ และคนของคุณก็มาร่วมได้: วงของคุณ ทายวันคลอด จดหมายถึงลูกน้อย และหนังสือของคุณ

อยู่ตรงไหน

พวกเรา

ใช้อย่างไร

  1. พวกเรา แสดงวงของคุณ: คู่ของคุณ และคนที่คุณเพิ่ม
  2. แบ่งปันข่าวคราว ส่งข่าวสั้นๆ ให้คนที่คุณเลือก — เฉพาะสิ่งที่คุณเลือก และเฉพาะตอนที่คุณส่ง
  3. ช่วงตั้งครรภ์ ทายวันคลอด: เพิ่มคำทายแรก (ภายหลังคือ เปิดดูคำทาย) แล้ว แชร์การทาย เพิ่มคำทายวันและน้ำหนักแต่ละคนเมื่อได้รับกลับมา
  4. เขียนจดหมายถึงลูกน้อย แล้วปิดผนึกไว้จนถึงวันที่คุณเลือก
  5. หนังสือของคุณจนถึงตอนนี้: Bloom เขียนหนังสือของคุณไปเรื่อยๆ — สัปดาห์ต่างๆ สิ่งที่คุณบันทึก จดหมาย การทายวันคลอด หนังสืออยู่ในโทรศัพท์ของคุณ
  6. ชวนเพื่อน: พวกเรา → ปุ่ม + ท้ายวงของคุณ (ชวนเพื่อน) → แชร์โค้ดของฉัน เพื่อนที่มี Bloom แล้วใส่โค้ดของคุณที่เดียวกัน ใต้ มีโค้ดไหม? แล้วแตะ ใช้โค้ด

ความเป็นส่วนตัวและข้อมูล

ช่วยอะไรคุณ

วันของคุณอยู่ในโทรศัพท์ ที่นี่คุณนำข้อมูลติดตัวไป ลบทิ้ง และเลือกว่า Bloom จะเก็บอะไรไว้

อยู่ตรงไหน

ฉัน → ความเป็นส่วนตัวและข้อมูล

ใช้อย่างไร

  1. ส่งออกข้อมูลของฉัน บันทึกทุกอย่างที่คุณบันทึกไว้เป็นไฟล์เดียว
  2. ลบข้อมูลทั้งหมดของฉัน ลบทุกอย่างออกจากโทรศัพท์เครื่องนี้ ย้อนกลับไม่ได้
  3. ลืมทุกอย่างที่ Bloom เรียนรู้ ล้างสิ่งที่ Bloom เรียนรู้เกี่ยวกับคุณ เสียงที่ Bloom จำได้ ให้คุณลืมเสียงที่เธอรู้จักได้
  4. สำรองความทรงจำของ Bloom: ถ้าคุณตอบ ตกลง เก็บความทรงจำของฉันไว้ สำเนาบันทึกความทรงจำของ Bloom — เฉพาะบันทึกนั้น — จะเก็บไว้บนเซิร์ฟเวอร์ของ Bloom โทรศัพท์เครื่องใหม่จึงยังจำคุณได้ ปิดเมื่อไร สำเนาก็ถูกลบ
  5. ล็อกแอป ตั้ง PIN 4 หลักที่ Bloom จะถามทุกครั้งที่เปิด
  6. ฉัน → สรุปสุขภาพ ทำสรุปส่วนตัวไว้ให้แพทย์หรือพยาบาลผดุงครรภ์ดู

ควรรู้

อะไรออกจากโทรศัพท์ เมื่อไร และเพราะอะไร: สรุปความเป็นส่วนตัว

Pro

ช่วยอะไรคุณ

Bloom ใช้ได้ฟรี Pro คือการจ่ายครั้งเดียว เป็นของคุณตลอดไป: ทุกสัปดาห์ของการตั้งครรภ์แบบเต็ม ตัวนับลูกดิ้น ตัวจับเวลามดลูกหดตัว — และเครื่องมือ Pro ที่จะตามมาภายหลัง

อยู่ตรงไหน

ฉัน → อัปเกรดเป็น Pro

ใช้อย่างไร

  1. แตะ ฉัน → อัปเกรดเป็น Pro — หรือ ปลดล็อกด้วย Pro บนเครื่องมือ Pro (เครื่องมือสำหรับ Pro)
  2. หน้าชำระเงินของสโตร์จะเปิดขึ้น — App Store หรือ Google Play — และสโตร์แสดงราคาตามที่คุณอยู่ Bloom ไม่เห็นบัตรของคุณเลย
  3. เมื่อสโตร์ยืนยัน Pro ก็เป็นของคุณ และเครื่องมือ Pro จะเปิดใช้ได้
  4. หลังติดตั้งใหม่ Pro มักกลับมาเอง ถ้าไม่กลับมา เขียนถึงเรา พร้อมใบเสร็จจากสโตร์ แล้วเราจะแก้ไขให้ค่ะ

Bloom ให้ข้อมูลทั่วไป ไม่ใช่คำแนะนำทางการแพทย์ และไม่ใช่วิธีคุมกำเนิด เรื่องสุขภาพทุกเรื่อง โปรดปรึกษาแพทย์หรือพยาบาลผดุงครรภ์ของคุณ ในกรณีฉุกเฉิน โทรหาหมายเลขฉุกเฉินในพื้นที่ของคุณ
